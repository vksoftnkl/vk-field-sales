Desktop findings while reading the code (not copied to the phone)

For the desktop team; line numbers are in NexERP src/modules/sales/salereturn/sale_return_entry.cpp.

  • Settle mode falls back to ADJUST. settleMode() returns ADJUST when the mode is empty, and loadBill clears it for another branch's bill, so Post can open the Adjust popup there (sale_return_entry.cpp 841-844, 1327, 2356).
  • Scans ignore the barcode's unit. A box barcode adds 1 in whatever unit the row is in (1749-1756).
  • Amend of a no-bill return. Calls /bill-lines with an empty sbId (2688).
  • List "Alter" does not start an amend. loadVoucher ignores openForEdit (1046).
  • Free returns off is only a warning. The screen warns (224-225); VK Nex then refuses SALES_RETURN_NO_BILL_OFF at post.
  • Typed adjust / refund rows lost. When Post saves a changed return first, applyLoaded resets them (1116-1118).
  • Amend sends money. srReturnAmt goes in the amend body despite the no-money rule (2585).
  • Refund popup with no refund block. Opens even when the server sent none (2540-2543).
  • "Too many" message. Its already-back figure leaves out this return's other split rows (518-519).
