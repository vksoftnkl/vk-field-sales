How it works

  • Opened from Customer detail → Return, or a return waiting on the phone. Called “Sales return” in the menu, here and in the report.
  • The reason is picked once, from VK Nex’s reason list (VK Nex keeps one reason per return).
  • Type the qty on the line, tap it for batch and dates, or tap the bin to remove it (the old app couldn’t).
  • Save keeps it as Pending; Sync sends it, the same as bills.

How it works

  • MRP and GST are locked; qty and price can be changed.
  • Batch date and Expiry date open the calendar (the same one as Ledger dates), not free text.
  • Every field has a label above it; one text size throughout.
  • Save goes back to the return; “Remove from return” takes the line off.

To decide before building

  1. Reason: one per return, as VK Nex keeps it (shown here), or one per line, as the old app had it?
  2. Against a bill: VK Nex can link a return to the bill it came from. Pick the bill on the phone, or send returns without a bill?
  3. Godown: VK Nex needs a godown on every return line. The same godown pick as bills, or one fixed godown (e.g. damaged stock)?
  4. Sending: VK Nex has no phone route for returns yet. Saved as a draft for the office to check, or posted at once like bills and receipts?
